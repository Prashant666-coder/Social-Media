# 📸 Social Media Practice Project

This project was built to practice full-stack web development using the MERN stack. The main goal was to understand how the frontend and backend communicate with each other while handling image uploads and database operations.

## 📚 What I Learned

During this project, I learned how to:

- Set up a MERN project from scratch.
- Build REST APIs using Express.js.
- Connect Node.js with MongoDB using Mongoose.
- Perform CRUD operations with MongoDB.
- Handle image uploads using Multer.
- Upload images to ImageKit Cloud Storage.
- Work with environment variables using dotenv.
- Send multipart/form-data from React to Express.
- Fetch and display data using Axios.
- Use React Hooks (`useState`, `useEffect`).
- Navigate between pages using React Router.
- Handle API requests and responses.
- Enable CORS for frontend-backend communication.
- Debug backend and frontend errors.
- Organize code into models, services, and routes.

## 🛠 Tech Stack

- React (Vite)
- React Router DOM
- Axios
- Node.js
- Express.js
- MongoDB
- Mongoose
- Multer
- ImageKit

## 🎯 Purpose

This is a learning project created to strengthen my understanding of full-stack web development and the complete flow of creating, storing, and displaying posts with images.
